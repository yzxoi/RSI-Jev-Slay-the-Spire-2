## 从这次实战学到了什么

胜利构筑主要依赖双无惧疼痛、重振精神、势不可当与风之女儿的联动；铁斩波自身格挡和攻击触发的格挡能够分别触发伤害。燎原之火提供后续能量，祭品和剑柄打击补充启动与抽牌，滚石提供持续伤害。最后给祭品附加固有/保留，改善了关键能力启动的时机。

女王的魂缚允许每回合只打出一张受影响的牌，后续抽牌不受该次束缚；实际判断需要等待开局抽牌和附加效果完成。黑暗镣铐把一次 25 点攻击降为 3 点。以上是这局观察到的有效决策，不是通过配对实验确认的独立因果提升。

下一步最短路径是把这些明确、可测的 Astra 判断变成计算模块和 Jev 的紧凑输入，再用新 seed 的 A10 配对验证；继续堆通用提示词缺少正面证据。已拆成独立实验：

- [E026 / #47](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/47)：长期能力与启动顺序。
- [E027 / #48](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/48)：原生回合开始的部分手牌与过早就绪。
- [E030 / #51](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/51)：多次格挡、消耗与伤害触发链的计算。
- [E032 / #54](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/54)：可格挡的回合末伤害与真实 HP 损失分开预测。

本里程碑完成了真实接入、完整流程、证据留存和一次胜利。低 Astra 成本、多角色高进阶强度和稳定整局速度仍是未完成目标。
