# 2026-10-03：PPO、经验重用与分支教师的阶段诊断

## 诊断

**目前的 PPO 在学单场战斗，尚未在优化整局决策。** critic 目标是战斗胜负与结束 HP，局外选择只有行为克隆；从这个目标不能推出网络会学会为后续 Boss 组牌、花钱和存药。宏观教师会强制选择精英，其他常规奖励通常取第一个选项，商店直接离开。它能准备困难入口，但不是已验证的强整局教师。E144 也说明：只取消精英偏置远远不够。

**没有发现明显的数值发散，但这不证明 PPO 实现或目标已经理想。** E140 的 16 次批次更新中，平均 KL 为 0.0028～0.0069、熵为 0.79～0.95，clip fraction 为 3.7%～8.2%。BC loss 与训练 value loss 下降，仍未对应新 seed 整局收益。不能只看 loss，也不能把不等数据/预算的 AWR 与 PPO 比较当成算法优劣的因果结论。

**数据覆盖在采集和采样两个位置都有缺口。** 自然策略大量死于第一幕，第三幕仍没有数据。E140 的循环列表把新铁甲第二幕入口放在后面，实际 fresh PPO 没抽到它们；其他角色的第二幕样本不能替代铁甲后期训练。下一轮必须按英雄×幕×难度检查实际配额，缺失时显式失败，不能静默用第一幕补足。

**更好的路径不等于可直接学习的好标签。** E142 的 8 个改善中，4 个仅改起手后贪心续演就有效，另外 4 个依赖后续随机动作序列。E143 已经证明，这批少量整条路径的普通 BC 没能优于等预算自模仿。未来要区分完整可执行示范、单步动作质量和价值目标，不能把选出的起手当成无偏 Q 标签。

**输入仍然有损。** E141 提供了经过检查的只读接口和顺序敏感编码，但没有把引擎全部计数器/触发器/RNG 变成完整 Markov 状态。现有描述是字符串哈希，不是语言语义表示；不能假定小网络天然理解新卡及其组合。为了隔离教师数据的效果，E143 保持旧阶段编码，尚未验证更丰富输入的学习收益。

## 计算资源

E133 优化器只占训练含验证总时长的约 0.855%；即使优化器无限快，总体也只快约 1.0086 倍。E142 的 452 条真实续演中，完整前缀恢复占累计路径时间约 87.1%，单路径中位 4.906 秒。当前优先级是有效数据、可认证恢复和实际批量推理，而不是追求 GPU 使用率。MPS 大批量的收益需要在真实异步采集器或更大模型上重新测量，不能套用微基准。

## 下一阶段的有界入口

[E145](../../../experiments/E145/README.md)已完成完整第一幕的 on-policy 正反馈诊断：24个TRAIN游戏seed各贪心+4次采样，共120次全部正常战败、零Boss遭遇，未产生梯度。全部128份引用轨迹审计通过。完整幕奖励密度门槛失败，不直接扩大稀疏终局训练。派生的六战前缀15/120成功（A0/A5/A10为10/4/1），另行登记这个较短目标的on-policy课程；前三战已117/120成功。

随后需要单独验证 E141 观测进入采集/训练的效果，并把 PPO 的轨迹边界扩到完整幕，使路线、奖励、选牌真正获得后续结果的信用。局部学习成功后仍须回到新 seed 的整局评估；最终 330-seed 验收不能由规划器或搜索接管。
