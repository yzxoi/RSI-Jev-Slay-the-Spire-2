# E063 — Letter Opener third-Skill trigger

Issue: [#118](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/118). Fixed baseline: merged main `0926445e779c29836ef9ac699babd964c3cb0f0a`, before the unmerged E062 hit-cap experiment. E062 observed one same-state divergence at headless state SHA-256 `119be17f20110dbd0c6ae55481d2727e8b18faf46306cf01b362b302aa249a9f`: baseline chose Tremble, treatment with hit-cap chose Bash and later exited the encounter at 52 rather than 67 HP. On the baseline route, Tremble and Purity were followed by Defend; after Defend, one enemy at 3 HP disappeared and another fell from 26 to 21 HP. The Letter Opener relic says each third Skill in a turn deals 5 to all enemies. This is strong evidence for the mechanism, but the exact damage ordering on blocked enemies is not established by that unblocked observation.

Hypothesis: tracking the number of Skills already played this turn and forecasting Letter Opener's third/sixth Skill AoE improves the approximate planner's damage and kill forecast without changing decisions when the relic is absent. Headless turn history must provide the counter because the pinned serializer omits it. Native combat export has `skills_played_this_turn`; native use requires separate validation. This experiment changes only the planner, not game state.

Fixed evaluation inputs: paired `planfixed` baseline versus `planfixed_letter` treatment on seeds `e062_cap_003` (development exposure) and `e063_letter_001`–`004` (held out), Ironclad and Silent at A0 and A10: 20 pairs/40 episodes, 1,500 actions or 180 seconds each, three workers, no model calls. Pin game v0.111.0, game DLL SHA-256 `9cb4f1ad8c9f284aa8fec3122ffd6d780bbf543d875c817abdd12ff63fbf12b4`, sts2-cli commit `084d1aa3d8e118ca7ce8d8774ad16d6be9c92367`, SDK 9.0.318. Record all selected episodes, normal defeat/victory/error/stall, same-state decision divergence, Letter Opener exposure, battle HP, act/floor, exact tested SHA and all raw trace hashes. This fixed macro comparator uses no Jev/Astra and cannot estimate Jev win rate.

Controls: no relic or fewer than three Skills retains baseline behavior; exact third and sixth Skills deal 5 to each living enemy; blocked targets are an internal-consistency synthetic case; unknown starting counter must not imply a trigger. The only native-observed parity case is unblocked. Promote only if the observed unblocked transition is matched, controls and full tests pass, all 40 episodes are accounted for without new execution errors, non-Letter states retain baseline decisions, and natural same-state divergences show no obvious safety regression. Sparse exposure or zero wins limits any strength claim. Failed implementations and their reasons remain in commit history; results go in this directory and PR comments.

## Iteration 1 — forecast alone regressed the exposed fight

`2d9cad2` added the Letter Opener forecast and an explicit headless Skill counter. `99b4d308fa4c14ec85478eb65bada3566eae6ded` made the counter unknown after opaque auto-play cards, added the fixed cohort evaluator and passed 101 repository tests. Command: `python3 -m scripts.evaluate_letter_e063`. [`iteration1-result.json`](iteration1-result.json) records 40/40 normal defeats, 40/40 verified raw trace hashes, 20 paired act/floor ties and zero model calls. Only the development Ironclad A0 seed reached Letter Opener; the four held-out seeds and other character/ascension pairs did not, so they cannot measure this mechanic.

There was one same-state action difference, precisely at the frozen E062 state. Baseline chose Tremble and left the battle at 67 HP after Burning Blood; treatment chose Purity and left at 52 HP, a **15-HP local regression**. The treatment plan imagined Purity, Defend, Tremble and Strike, forecasting a third-Skill proc. Actual fixed macro selection after Purity exhausted Tremble, so the imagined continuation was impossible. This is an inference from the selected-action and state-transition trace, not a randomized causal estimate. [`iteration1-analysis.json`](iteration1-analysis.json) summarizes the divergence. The preregistered no-obvious-harm condition failed; do not promote this iteration. Next iteration will stop forecast search after a card that can alter the remaining hand, then rerun the same fixed cohort without changing seeds or budgets.

## Iteration 2 — stop plans at hand-changing effects

`68786e3cde2461c894c0a31050a66c695a8b67f2` stops a Letter Opener forecast after Purity, Burning Pact, True Grit, Second Wind or Cascade changes the hand; subsequent actions are replanned from observed state. The frozen regression control rejects a Purity-first fantasy and all 102 tests pass. Repeating `python3 -m scripts.evaluate_letter_e063` on the same 40 episodes gave 40/40 normal defeats, 40/40 verified trace hashes and 20 paired act/floor ties. Only development Ironclad A0 had the relic, with nine treatment states forecasting a proc. The two same-state differences in that pair had battle-exit HP 67→67 and 38→41 (baseline→treatment). Other selected pairs had no relic exposure or decision differences. See [`iteration2-result.json`](iteration2-result.json) and [`iteration2-analysis.json`](iteration2-analysis.json). This removes the observed safety regression and gives a 3-HP local improvement in one fight, but still provides no win-rate evidence. A native opt-in adapter is the next compatibility step; it will use the game's explicit current-turn Skill count rather than reconstructing it from headless actions.

`774bcb55187d63da7890af4c5bc4e45b9e195cb5` added that opt-in native adapter as `--letter-opener-plan` and a synthetic native projection test using `skills_played_this_turn=2`; no visible native action was taken. After merging current main (including E059 and E064) at `5c0201b138200bd4b6ec0a83b0c57e385106b5c0`, all 106 tests passed and both native experiment flags appeared in `python3 -m rsi.campaign --help`. The native projection's blocked-target behavior and other trigger ordering remain model assumptions until observed in real play.

Decision: promote **only as opt-in planning code**. The corrected cohort met the frozen local correctness and no-obvious-harm criteria, but only one in-sample pair had the relic, no selected run won, and the native adapter has not yet acted in a real game. Do not enable by default or infer high-ascension or full-run strength from this result. [`result.json`](result.json) summarizes the two versioned cohorts and exact code SHAs; failed iteration 1 and its traces remain accessible.
