# E061 — one reviewed dangerous turn, bounded execution lease

Issue: [#113](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/113). Hypothesis: after a state-fingerprint-bound Astra opener has been accepted, Jev can execute the remaining legal actions of that **same turn** without repeated current-HP review pauses. This should reduce the E059 floor-8 fight's seven manual Astra steps to at most two turn approvals. This is an execution-overhead experiment, not evidence of a better battle policy or counterfactual win.

Baseline: merged `origin/main` `938c5e14defb5de1b8d697cf38ba841923529c86`, game v0.111.0/mod 0.15.0, Jev `typesafe/jev-1.13-20260917`. The current controller's `--pause-on-danger --danger-hp 20` gate pauses again after each E059 floor-8 manual step at 18→17 HP, requiring seven state-bound Astra actions (four in turn 3, three in turn 4). Source run `EC0JQCUP6QMC`, floor 8, original raw trace SHA-256 values and state hashes are frozen in `frozen-floor8-review.json`. The fixture includes only control-flow-relevant native state fields, not game binaries, credentials or full raw traces. The source results and full ignored traces remain in E059. No rollback or new native action is part of this first evaluation.

Implementation boundary: an explicit `--review-lease` flag must require `--expert-choice`; the accepted expert action binds the lease to run ID, floor, turn, and the first post-action fingerprint. The expected fingerprint advances only after each accepted action. A changed run, floor, turn, scene, unexpected state hash, unknown attack total, HP mismatch or unsafe/unknown Beckon projection revokes it. Only the low-current-HP pause is suppressible; E056 projected-large-loss review, explicit card review, sandpit review, E055 end-turn/Beckon guards, legal candidate recomputation, one-writer checks and action freshness remain active. Later turns require a new expert opener.

Fixed evaluation: replay the seven E059 source transitions in time order as an offline control-flow trace. Include synthetic tests for a changed run ID, new turn, stale fingerprint, newly lethal end turn, Beckon self-loss and unmodelled enemy attack. Run the complete unit suite. Promotion requires at most two Astra approvals on the frozen fight, no hard-safety bypass, lease revocation in every negative control, and passing tests. Trace hashes and exact tested SHA will be recorded beside this plan before the PR decision. A fresh visible run is needed later to measure actual Jev actions, token cost and game outcomes under the lease.

## Result and decision

Tested implementation SHA: `a7f44f65555074a521b4ead66e95b99596e2ee86`. The extracted seven source trace hashes were verified against E059's ignored local raw traces before the fixture was committed. Command: `python3 -m unittest discover -s tests -v` (95 passed, 0 failed). The frozen seven state-bound manual actions group into two turns; replay with an accepted opener in each turn needs **two Astra approvals** and suppresses five repeated current-HP pauses. Changed run, new turn, stale fingerprint, unknown attack total and lethal Beckon controls revoke the lease; a newly lethal end turn still triggers the independent hard guard, and E056's high-HP projected-loss alert still fires. Exact inputs, source trace hashes and measured counts are in [`results.json`](results.json).

Decision: promote the explicitly opt-in `--review-lease` compatibility feature. It changes no default controller behavior. The result supports less repeated review on the fixed control-flow trace only; it does **not** show Jev would make the same choices, survive the encounter, or improve run win rate. The first fresh native use should be bounded to one turn, with raw trace and model cost retained for an outcome evaluation.
