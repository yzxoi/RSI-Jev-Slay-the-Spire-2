# E077 — A10 critical-HP combat weight replication

Issue: [#146](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/146). Baseline: merged `origin/main` `a7c2469f86777f2cef2d1bef6fd68ac30fe42ca7` with E076's card-selection request cap. E073's exploratory A10 subgroup had 2 deeper, 0 shallower and 6 tied matched pairs; its complete mixed-A0/A10 cohort failed the overall rule and had two A0 simulator errors. The subgroup is a lead to replicate, not evidence of general improvement.

Hypothesis: at A10, increasing the forecast HP-loss coefficient from 1.5 to 3.0 **only when current HP/maxHP ≤0.40** improves run progression. The baseline is the merged `retaliate` policy. Opt-in `retaliate_lowhp` retains the same macro Jev prompt, legal choices, planner width/depth, triggers and retaliation; the low-HP coefficient alone differs. No HP, rewards, RNG or victory values are edited.

Frozen evaluation before implementation: seeds `e077_a10_001` through `_008`, Ironclad and Silent, A10, baseline and treatment: 16 matched pairs / 32 full-run CLI episodes. Each episode is limited to 1,500 steps and 180 seconds. Four workers share 5,000 Jev calls / $1.50. Pinned game v0.111.0, sts2-cli `084d1aa3d8e118ca7ce8d8774ad16d6be9c92367`, Jev `typesafe/jev-1.13-20260917`. Command: `python3 -m scripts.evaluate_lowhp_e077`. Commit implementation before evaluation; preserve every ignored raw trace and publish compact per-run outcomes, exact code/dependency hashes, costs and verified trace hashes.

Decision: all 32 episodes must finish as a normal victory or defeat with zero execution errors; at least 10 same-state first-action differences at or below 40% HP and zero above; ≥5 matched pairs deeper, ≤2 shallower and no baseline victory turned into a loss. Merge the opt-in policy only if all criteria pass. Otherwise close as negative/inconclusive. Progression at this sample size is exploratory, not a win-rate estimate; any positive result requires broader and native validation.
