# E074 — repair missing headless Vector2I.One API

Issue: [#140](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/140). Baseline: merged `origin/main` `0ab503b2a225d2aac1c031d4d13bff4a4b9d5253`. In E072 and E073, three deep CLI runs failed at `event_choice` with `MissingMethodException: Method not found: 'Godot.Vector2I Godot.Vector2I.get_One()'`. The pinned Godot stub defines `Vector2I.Zero` but not `One`. This is simulator correctness, not policy strength.

Hypothesis: adding exactly `Vector2I.One` to the isolated pinned stub will allow the same command sequences to complete their previously failing `choose_option`. Freeze two [command transcripts](frozen-commands.json): E072 baseline Ironclad A0 `e072_loss_003`, 277 commands from local wire SHA-256 `3965587462a2ba87e89ef15faa88647d1151d7bca2d73cf3c2d504f54d97a6e4`; E073 treatment Ironclad A0 `e073_lowhp_001`, 493 commands from wire SHA-256 `dbc3af55172df7f20a1406a0c7e74245967b5b5353767e56dec0a32f45551338`. Both have failing final `choose_option` index 0. The frozen file includes the hash of each state immediately before that action. The source raw wire stays ignored. These are deterministic replays with no Jev, HP/RNG/reward/victory edits or full-run win claim.

Decision: first reproduce both MissingMethodExceptions using the unpatched pinned CLI and record any mismatch. Then apply a minimal patch in an isolated local checkout, rebuild and replay both. Merge only if both reach the frozen pre-error state, complete the final action without an error, original game DLL hash is unchanged, and repository tests pass. Record exact code, patch, assembly and game hashes plus replay outcomes; otherwise close as inconclusive. Command: `python3 -m scripts.replay_vector2i_e074 --expect-error` for baseline, then `python3 -m scripts.replay_vector2i_e074` after patch and rebuild.

Baseline replay harness at exact tested SHA `a9cd44fee1e59e9961529084a2d8ee8f61188939` passed `python3 -m unittest discover -s tests -q` (112 tests) and `python3 -m py_compile scripts/replay_vector2i_e074.py`. The fixed `python3 -m scripts.replay_vector2i_e074 --expect-error` reproduced both failures in a separate copied CLI checkout: 277-command E072 and 493-command E073 replays matched their exact frozen pre-final state hashes and failed on their final `choose_option` with `Godot.Vector2I.get_One()`. [`baseline-result.json`](baseline-result.json) records original game/assembly/patch hashes, accepted pre-error command count, exact error and verified local replay wire hashes. This establishes a deterministic compatibility regression, not a policy result.

Minimal fix iteration at exact tested SHA `dcd686fe3d734fc684332fbb5581252f074022bb` added one `Vector2I.One` static property through [`headless-zzzzz-vector2i-one.patch`](../../patches/headless-zzzzz-vector2i-one.patch) and allowed the pinned setup script to reconstruct this managed stub file. `python3 -m unittest discover -s tests -q` passed 112 tests. `python3 scripts/setup_headless.py` rebuilt the isolated CLI with zero build errors. Original game DLL SHA-256 remained `9cb4f1ad8c9f284aa8fec3122ffd6d780bbf543d875c817abdd12ff63fbf12b4`; the patched assembly SHA-256 is `d04aaad3f0b33cbec0d6d7ba5eeda71ec35ad54f84d9b8eda12e51e3242aa66c`, versus baseline `ad5fc0f5958958d5a0473b81525642bbc8ddff33ea07d90fe675b6f3fdfc99ad`.

The same frozen command `python3 -m scripts.replay_vector2i_e074` at that SHA matched both exact pre-final state hashes again, but **both final actions still failed**, now with `NullReferenceException` instead of the missing method. [`patched-result.json`](patched-result.json) records both errors and local wire hashes. Raw stack traces place the new failure at `NCrystalSphereScreen.ShowScreen(CrystalSphereMinigame)`: the headless CLI logs that `res://scenes/events/custom/crystal_sphere/crystal_sphere_screen.tscn` is not cached. Decompiled game code confirms `ShowScreen` requests that visual scene before the minigame can complete. The one-property fix removes the first exception but does not make the UI-backed event playable in headless. No gameplay outcome or win claim follows from these replays.

Decision: **close the E074 PR without merging**. The predeclared rule required both formerly failing actions to complete; neither did. Preserve the failed patch iteration, baseline and patched traces on this branch. A new atomic issue should address the Crystal Sphere event's visual-scene/minigame boundary directly, with legal decisions and real game effects, rather than accumulating unverified stub shims.
