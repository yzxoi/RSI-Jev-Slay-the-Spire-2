These are deterministic replays with no Jev, HP/RNG/reward/victory edits or full-run win claim.

Decision: first reproduce both MissingMethodExceptions using the unpatched pinned CLI and record any mismatch. Then apply a minimal patch in an isolated local checkout, rebuild and replay both. Merge only if both reach the frozen pre-error state, complete the final action without an error, original game DLL hash is unchanged, and repository tests pass. Record exact code, patch, assembly and game hashes plus replay outcomes; otherwise close as inconclusive.
