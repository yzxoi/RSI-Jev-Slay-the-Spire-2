# E080 — held-out Act 1 Boss buff policy

Issue: [#152](https://github.com/yzxoi/RSI-Jev-Slay-the-Spire-2/issues/152). Baseline: merged `origin/main` `8ea843d434a64fedd3247a2dafd6f6092fab8293`, policy `retaliate`. E079 replayed two selected E077 Boss entries and one Ironclad branch cleared the Boss after Liquid Bronze + Dexterity. That is selected battle evidence, not an estimate of new-seed run strength.

Hypothesis: an opt-in `retaliate_boss_buffs` policy that spends legal battle-long buff potions on **Act 1 Boss round 1**, before any card, improves held-out A10 complete-run progress. Priority is Liquid Bronze, Dexterity Potion, Strength Potion, Fysh Oil; use each available potion in that order with a fresh state read between actions. All other potions remain reserved. The treatment otherwise uses the same Jev macro prompt, legal rewards/routes, combat planner, search parameters and RNG as baseline. No HP, rewards or victory values are edited.

Frozen held-out evaluation before implementation: seeds `e080_boss_001`–`_012`, Ironclad and Silent, A10, baseline and treatment: 24 matched pairs / 48 complete-run CLI episodes. Four workers, up to 4,000 decisions and 600 seconds per episode; shared 10,000 Jev calls / $2.00. Use MatchedJev to cache identical macro requests. Pinned game v0.111.0, sts2-cli `084d1aa3d8e118ca7ce8d8774ad16d6be9c92367`, Jev `typesafe/jev-1.13-20260917`. Command: `python3 -m scripts.evaluate_boss_buffs_e080`. Preserve ignored raw traces and verify every SHA-256 value; publish exact tested SHA/dependencies, first-intervention state/action-prefix parity, potion consumption, all episode status/act/floor, model usage and failures.

Decision: all 48 episodes must end normally without execution error; at least two treatment pairs must execute a legal Boss buff from exactly the same pre-intervention state and action prefix as baseline, with confirmed inventory decrease; no-intervention pairs must remain identical. At least two pairs must progress farther and at most one regress, including at least one treatment entering Act 2 when baseline did not. No baseline victory may become a loss. Only then merge as an opt-in candidate for broader/native testing. Otherwise close as negative or inconclusive. This sample is not a win-rate estimate or an Act 3 victory claim.
