# E043 — Draw-lock-aware ordering

Issue #77. Hypothesis: explicitly tracking Battle Trance's no-draw effect in the approximate combat planner will choose a draw-producing attack before Battle Trance when both can be played without sacrificing a lethal or survival line. The simple baseline is the current E041 planner: it awards every draw effect utility even after no-draw and deduplicates plans without a draw-lock state. On E042's native boss turn-8 state with Pommel Strike and Battle Trance+ both playable, that baseline proposes Battle Trance+ first. The native E042 turn-4 trace independently shows Battle Trance+ granting `NO_DRAW_POWER`, followed by Pommel Strike and another Battle Trance producing no new cards. `frozen-turn8.json` holds a sanitized normalized input and candidate set; `native-evidence.json` records the factual before/after counts and ignored raw trace SHA-256. These are mechanism inputs, not a counterfactual battle replay.

Fixed evaluation before implementation: run the baseline and treatment planner on `frozen-turn8.json`; assert Pommel-first ordering in the treatment, while controls with no Battle Trance, pre-existing no-draw power, or an immediate guaranteed lethal do not gain fictitious draw value. Use the same four deterministic headless A0 `planfixed` runs for both versions: characters `Ironclad,Silent`, seeds `e043_draw_001,e043_draw_002`, policy `planfixed`, two workers, 4000-step built-in cap. Exact command per version: `python3 -m rsi.full --characters Ironclad,Silent --seeds e043_draw_001,e043_draw_002 --policies planfixed --ascension 0 --workers 2 --max-calls 0 --max-usd 0 --output artifacts/runs/e043-{baseline|treatment}.json`. `planfixed` keeps macro decisions deterministic and isolates the combat planner; it does not test Jev's own choice quality. Compare terminal status, floors, HP, action/stall/error counts and how often both relevant cards are simultaneously playable. Four runs are exploratory, not a win-rate estimate. No live game writer is used; the E042 run has already ended normally.

The implementation should carry draw-lock through the search state and discount later draw utility; do not simulate unknown drawn cards or silently alter native action semantics. Record exact tested commit SHA, game/headless/model versions, commands, results, trace hashes and iteration reason after each run. Decision rule: merge a mechanism correction only if frozen factual transitions and controls pass. Promote the default planner policy only if the matched full runs include an exposed scene and show no new compatibility errors; if exposure is absent or a regression appears, close the policy experiment with preserved history and report the limited mechanism result. This gate does not infer whole-run benefit from the single E042 turn.

Baseline at `c92c0048c6578efa6a24677caa24fbfcf10c731f`: the frozen native turn-8 planner proposed Battle Trance+ first, then Perfected Strike, Pommel Strike and Strike (`score=24.25`). The four predeclared `planfixed` A0 runs had **zero** scenes with both Battle Trance and Pommel Strike playable; three ended normal defeats and Silent seed `e043_draw_001` stopped with the unrelated headless `Godot.Vector2I.get_One()` missing-method error at act2/floor5. Exact per-run traces, statuses and exposure counts are in `baseline-planfixed.json`. No gameplay effect can be inferred from this cohort, and the compatibility error remains in all comparisons.

Iteration-2 baseline at `8fa117878b60941a3d06c99056df592c3f5cae15`: all three Ironclad runs ended normal defeats (act1/floors13,8; act2/floor4), 72 Jev calls/$0.011555418 total. No scene had both Battle Trance and Pommel Strike playable. A separate, mechanically relevant exposure appeared in seed `a0_e038_dev_002`: 49 scenes had the exported `No Draw` power, and six of those still offered a playable card with a positive draw count. The headless serializer exports this as top-level `player_powers` with name `No Draw`, whereas native normalized state uses `player.powers`/`NO_DRAW_POWER`. The initial simultaneous-card metric missed this second path; count both exact conditions in treatment, without retroactively replacing the fixed cohort or claiming a win. `baseline-jev.json` and the amended `baseline-planfixed.json` record both exposure types for every seed. The next implementation must recognize both serializer shapes; this is a documented extension of the mechanism input after baseline, before treatment.

Treatment implementation at `d02268789441ce0b4fd921f836f7436dc13ad91e` carries a `draw_locked` flag through current-hand search, initializes it from either native `NO_DRAW_POWER` or headless `No Draw`, sets it after Battle Trance's own draw, and credits subsequent draw effects zero draw utility. The native frozen turn-8 fixture now proposes Pommel Strike before Battle Trance+ with the same approximated endpoint score of 24.25; native trace observations show the prior Battle Trance+ added No Draw, then Pommel and another Battle Trance changed hand count only by the spent card and did not reduce the draw pile. The no-Battle-Trance control still opens with Perfected Strike; pre-existing lock controls in both serializer shapes open with Perfected Strike rather than assigning Battle Trance imaginary draw. `python3 -m unittest discover -s tests -p 'test_*.py'` passed 58 tests. This establishes the local mechanism, not a run win.

The same four `planfixed` A0 runs on treatment gave identical statuses, floors and step counts to baseline: three normal defeats and the same Silent `Godot.Vector2I.get_One()` compatibility error. Neither arm exposed a draw-lock decision in this cohort. The three `retaliate` Jev-macro treatment runs all ended normal defeats: seeds 001/002/003 reached act1/floor14, act2/floor4 and act1/floor12 respectively versus baseline act1/floor13, act2/floor4 and act1/floor8. These differences **cannot** be attributed to the planner change: the first same-state action difference happened in a Jev card reward, initial event and map route respectively, before any shared exposed draw-lock state. Baseline seed002's six locked-plus-draw scenes were not shared with treatment; treatment reached a different trajectory at its first event. `comparison.json` gives per-seed exposure, shared-state action counts and first divergence, while `treatment-planfixed.json` and `treatment-jev.json` give exact SHAs, costs, statuses and trace hashes. Both versions used game v0.111.0 / headless commit `084d1aa3d8e118ca7ce8d8774ad16d6be9c92367`; Jev cohort used `typesafe/jev-1.13`.

Decision: close this default-policy PR without merging. The mechanism correction passes the frozen evidence and controls, but the preregistered default-policy gate needs a matched exposed full-run comparison. It did not occur in seven fixed pairs, and all observed full runs lost. Keep the implementation and negative evaluation on this PR branch for a future replay/matched-decision experiment; do not claim a win-rate or stability improvement. The unrelated headless compatibility error is unchanged. E039/#70 already tracks stronger verified rollout/replay machinery, so no duplicate infrastructure experiment is opened here.
